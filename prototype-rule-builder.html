Test a claim

Pick a synthetic claim. The result below always includes both the saved rule set and whatever rule you are currently drafting above, so you can see the effect before you save it.

Both tracks are decided by the same winning rule, the same way the legacy engine's single dbo.fillAutobiller lookup picks one rule and reads its Pro and Tech output columns. When two matching rules tie on every specificity dimension, the legacy system (dbo.bOptsF) breaks the tie unpredictably, by columns nobody chose for that purpose. Here the tie is broken by the explicit priority number you set above, lower wins.
